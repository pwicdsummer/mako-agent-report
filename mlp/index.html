算法

四个 XOR 样本按 (0,0)、(0,1)、(1,0)、(1,1) 排列，标签为 0、1、1、0。默认网络包含 9 个参数。

前向传播

H = σ(XW + bₕ)
p = σ(Hv + bₒ)
L = −mean[y ln p + (1−y) ln(1−p)]

反向传播

δₒ = (p − y) / 4
∇v = Hᵀδₒ,  ∇bₒ = Σδₒ
δₕ = (δₒvᵀ) ⊙ H ⊙ (1−H)
∇W = Xᵀδₕ,  ∇bₕ = Σδₕ

Adam 更新

gₜ = ∇L(θₜ₋₁)
mₜ = 0.9mₜ₋₁ + 0.1gₜ
sₜ = 0.999sₜ₋₁ + 0.001gₜ²
m̂ₜ = mₜ / (1−0.9ᵗ),  ŝₜ = sₜ / (1−0.999ᵗ)
θₜ = θₜ₋₁ − ηm̂ₜ / (√ŝₜ + 10⁻⁸)
