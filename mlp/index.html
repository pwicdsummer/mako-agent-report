02   /   UNDER THE HOOD

从一个预测，走到下一次更新。

模型负责表达，损失衡量偏差。
反向传播求梯度，优化器改变参数。

01

准备数据与参数

输入 X ∈ ℝ⁴ˣ²，标签 y = [0, 1, 1, 0]ᵀ。W 有 4 个权重，bₕ 有 2 个偏置，v 有 2 个权重，bₒ 有 1 个偏置，共 9 个参数。

W = [[2, −2], [−2, 2]]
bₕ = [−1, −1]
v = [3, 3]ᵀ   bₒ = −2.5
02

前向传播与损失

Sigmoid 隐藏层组合两个输入，输出层产生分数 zₒ，再转为概率。BCE 衡量预测概率与目标标签的差异。

H = σ(XW + bₕ)
zₒ = Hv + bₒ   p = σ(zₒ)
L = −mean[y ln p + (1−y) ln(1−p)]
03

链式法则反向求导

从输出误差向前传递，得到每个参数对平均损失的梯度。这里 δₒ 已除以样本数 N = 4，后续求和无需再除。

δₒ = (p − y) / N
∇v = Hᵀδₒ   ∇bₒ = Σδₒ
δₕ = (δₒvᵀ) ⊙ H ⊙ (1−H)
∇W = Xᵀδₕ   ∇bₕ = Σδₕ
04

Adam 更新，重复学习

Adam 累积梯度的一、二阶矩，并作偏差修正。框架示例由 autograd / GradientTape 求导；网页显式实现同样的梯度。

mₜ = .9mₜ₋₁ + .1gₜ
vₜ = .999vₜ₋₁ + .001gₜ²
m̂ₜ = mₜ / (1−.9ᵗ)
v̂ₜ = vₜ / (1−.999ᵗ)
θₜ = θₜ₋₁ − ηm̂ₜ / (√v̂ₜ + 10⁻⁸)

WHY A HIDDEN LAYER?

相同标签分布在对角，一条直线无法分开。

没有隐藏层时，p = σ(w₁x₁ + w₂x₂ + b) 的分类边界始终是一条直线。隐藏层先构造非线性特征，再由输出层组合，从而拟合 XOR。这里使用可微的 Sigmoid，才能通过链式法则训练；阈值只用于最后的分类判断。

↳ 观察一

准确率相同，损失仍会下降。

训练达到 100% 准确率后，学习仍会把正确类别的概率推向更可信的值。所以必须同时看交叉熵与预测概率，而不只看分类是否正确。

↳ 观察二

参数设置会改变学习速度。

固定数据和初始化后，只改变学习率或优化器，比较同样 300 轮之后的 BCE。学习率并非越大越好；单次小规模实验不能推出所有任务的最佳设置。

↳ 观察三

拟合真值表，不等于证明泛化。

本实验穷举四个布尔输入，没有独立测试集。图上连续区域只是模型在非布尔坐标处的延伸，不能据此声称获得了测试准确率或真实任务的泛化能力。

optimizer = torch.optim.Adam(parameters, lr=0.03)
for epoch in range(1, 301):
    optimizer.zero_grad(set_to_none=True)
    hidden = torch.sigmoid(x @ W + b_hidden)
    logits = hidden @ v + b_output
    loss = F.binary_cross_entropy_with_logits(logits, target)
    loss.backward()       # 反向传播：计算每个参数的梯度
    optimizer.step()      # Adam：更新参数

# 使用更新后的参数重新计算并记录损失与预测。
